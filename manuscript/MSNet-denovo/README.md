# MSNet‑de novo

This directory contains the code for de novo peptide sequencing (MSNet‑de novo) used in the manuscript.

## Contents

| File / Directory | Description |
|------------------|-------------|
| `figure5/` | Scripts and data to reproduce Figure 5 from the manuscript. |
| `figure5/fig5a.py` | Script for Figure 5A — protein/peptide coverage analysis. |
| `figure5/fig5b.py` | Script for Figure 5B — de novo sequencing accuracy evaluation. |
| `figure5/fig5c.py` | Script for Figure 5C — performance comparison across tools. |
| `figure5/fig5c_precursors.csv` | Precursor data used in Figure 5C. |
| `figure5/fig5a_summary_helixmsnet.csv` | Summary data for HelixMSNet (Figure 5A). |
| `figure5/fig5a_summary_helixraw.csv` | Summary data for HelixRaw (Figure 5A). |
